## ADDED Requirements

### Requirement: LOYO is visible in the default Optimization report
When canonical LOYO robustness output exists, the default Optimization HTML report MUST render it from persisted artifacts without recomputing optimization in the browser.

## REMOVED Requirements

### Requirement: Portfolio / Asset Correlations
Optimization reports MUST NOT expose a separate portfolio/asset/benchmark correlation matrix. Asset Correlations remains the supported correlation view.
