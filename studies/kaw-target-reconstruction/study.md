# KAW Target Reconstruction Study

Reconstruct the current Kim Seong-il K-All Weather portfolio as a reproducible FDR-backed benchmark for later comparison against the user's TO-BE portfolio.

Current phase:
- Inspect native FDR coverage for the supplied nine Korean-listed ETFs.
- Use the observed coverage to decide Direct Proxy candidates and, where needed, KAW Core fallback sleeves.
- Distinguish KAW Core, Current-Native, and Current-Stitched before the final benchmark comparison.

The first experiment is a data-coverage probe only. Its dummy portfolio weights are not an investment allocation and its performance metrics are not used for research conclusions.
